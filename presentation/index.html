🌱 Sprig-DB

Ultra-lightweight, embedded key-value document database built entirely in Go — with a built-in REST API, admin dashboard, and multi-tenant authentication.

🔧 Language: Go (Golang)

🎯 Problem Statement & Relevance

The Problem

Modern apps face a setup complexity barrier for lightweight data persistence:

🗄️
SQLite
Requires SQL knowledge & rigid schemas upfront
🍃
MongoDB
Needs a separate server, heavy dependencies
⚡
Redis
In-memory only, no persistent document storage
☁️
Firebase / Supabase
Requires internet & cloud dependency

The Gap

No single-binary, zero-configuration, embeddable document database for Go that provides:

  • Schema-flexible JSON document storage
  • Built-in REST API & admin dashboard
  • JWT-secured multi-tenant access
  • SQL-like querying on NoSQL data
  • Automatic secondary indexing
  • Zero external dependencies

Relevance

🔌
Microservices & Edge/IoT
Lightweight embedded DB for constrained environments
📚
Educational
Learn DB internals (B+ trees, ACID, indexing)
⚡
Rapid Prototyping
Store structured data with zero setup
